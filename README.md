# 🧠 DecisionVerse
### Multi-Agent Decision Intelligence System

DecisionVerse is an AI-powered decision-support application that helps users compare alternatives through specialized AI agents, structured scoring, financial analysis, risk assessment, future simulations, and sensitivity analysis.

Instead of relying on a single AI-generated recommendation, DecisionVerse evaluates decisions across multiple dimensions and provides transparent, explainable results.

Built using **Python, LangGraph, Groq LLMs, and Streamlit**.

---

## 🚀 Overview

Making important decisions often requires balancing multiple competing factors.

For example, when choosing between two job offers, a person may need to consider:

- Salary and financial savings
- Career growth and learning opportunities
- Work-life balance
- Job security and uncertainty
- Long-term financial outcomes
- Personal priorities

DecisionVerse simplifies this process by using specialized AI agents to evaluate each option independently and combine their results into a structured recommendation.

The application also allows users to explore how changing their priorities affects the final decision.

## ✨ Key Features

### 🤖 1. Multi-Agent Decision Analysis

DecisionVerse uses specialized agents to evaluate different aspects of a decision.

**Career Agent**
- Evaluates professional growth opportunities.
- Analyzes learning potential and career development.
- Identifies strengths and uncertainties.
- Generates a career score.

**Finance Agent**
- Estimates monthly take-home salary.
- Calculates living expenses and monthly savings.
- Computes annual savings and savings rates.
- Generates five-year financial projections.
- Produces a financial score.

**Lifestyle Agent**
- Evaluates work arrangements and flexibility.
- Considers lifestyle-related advantages and disadvantages.
- Identifies potential work-life balance trade-offs.
- Generates a lifestyle score.

**Risk Agent**
- Identifies uncertainties associated with each option.
- Evaluates available information about job security.
- Highlights missing evidence.
- Suggests risk mitigation steps.
- Generates a heuristic risk-safety score.

**Decision Agent**
- Combines the results of the analysis.
- Explains the final recommendation.
- Highlights important trade-offs.
- Suggests practical next steps.

---

### 📊 2. Transparent Weighted Scoring

DecisionVerse combines the scores generated by individual agents using a weighted scoring mechanism.

The weights are determined by the user's stated priorities.

The overall score is calculated as:

\[
S = w_c C + w_f F + w_l L + w_r R
\]

Where:

- \(C\): Career score
- \(F\): Finance score
- \(L\): Lifestyle score
- \(R\): Risk-safety score
- \(w_c, w_f, w_l, w_r\): Corresponding weights

The weights satisfy:

\[
w_c + w_f + w_l + w_r = 1
\]

Each agent produces a score on a scale of 0 to 10.

The application displays:

- Individual agent scores
- Scoring weights
- Weighted contributions
- Overall scores
- Final recommendation
- Decision margin

This makes the recommendation interpretable and allows users to understand which factors influenced the outcome.

---

### 💰 3. Financial Analysis

The Finance Agent provides a structured comparison of financial outcomes.

For each option, DecisionVerse calculates:

- Estimated monthly in-hand salary
- Monthly living expenses
- Monthly savings
- Annual savings
- Savings rate
- Five-year cumulative savings

#### Financial Assumptions

Users can configure:

| Parameter | Default Value |
|-----------|---------------|
| Estimated take-home salary | 75% |
| Annual salary growth | 8% |
| Annual living-cost inflation | 6% |

These assumptions are adjustable through the Streamlit sidebar.

#### Monthly Savings

\[
\text{Monthly Savings}
=
\text{Monthly In-hand Salary}
-
\text{Monthly Living Expenses}
\]

#### Annual Savings

\[
\text{Annual Savings}
=
12 \times \text{Monthly Savings}
\]

#### Savings Rate

\[
\text{Savings Rate}
=
\frac{\text{Monthly Savings}}{\text{Monthly In-hand Salary}}
\times 100
\]

#### Five-Year Projection

The application estimates future salaries, living costs, annual savings, and cumulative savings using the configured growth and inflation assumptions.

These are simplified projections rather than guaranteed financial outcomes.

---

### 🔮 4. Future Timeline Simulation

DecisionVerse generates illustrative future scenarios for each option at three time horizons:

- Year 1
- Year 3
- Year 5

Each scenario considers:

**Career**
- Possible responsibilities
- Professional development
- Career progression uncertainties

**Finance**
- Estimated annual savings
- Cumulative savings

**Lifestyle**
- Work arrangements
- Flexibility
- Lifestyle-related considerations

**Risk**
- Potential uncertainties
- Missing information
- Risk-related considerations

The simulations combine structured financial projections with AI-generated scenario descriptions.

They are intended to support decision-making and should not be interpreted as guaranteed predictions.

---

### 🎛️ 5. Interactive Sensitivity Analysis

DecisionVerse allows users to modify the importance of four decision factors:

- Career
- Finance
- Lifestyle
- Risk

The application automatically normalizes the selected weights and recalculates the overall scores.

Sensitivity analysis does not rerun the AI agents.

Instead, it uses the previously generated agent scores to provide immediate feedback.

Users can observe:

- Updated scores
- Updated recommendations
- Decision margins
- Normalized weights
- Changes from the original scores

This helps users understand how their preferences influence the recommendation.

**Note:** A recommendation changes only when the underlying agent scores contain sufficient trade-offs between options.

---

### ⚖️ 6. Explainable Recommendations

DecisionVerse does not simply identify the highest-scoring option.

It also provides:

- A written recommendation
- A decision-strength classification
- Key advantages and disadvantages
- Financial comparisons
- Important uncertainties
- Recommended next steps

The decision margin is used to distinguish close decisions from stronger preferences.

## 🏗️ System Architecture

DecisionVerse uses LangGraph to orchestrate multiple agents through a shared decision state.

### Workflow

```text
                  User Input
                      |
                      v
               Supervisor Agent
                      |
                      v
                Extractor Agent
                      |
          +-----------+-----------+
          |           |           |
          v           v           v
     Career Agent  Finance Agent  Lifestyle Agent
          |           |           |
          +-----------+-----------+
                      |
                      v
                 Aggregator
                      |
                      v
                  Risk Agent
                      |
                      v
              Score Aggregator
                      |
                      v
              Simulation Agent
                      |
                      v
                Decision Agent
                      |
                      v
              Final Recommendation
                      |
                      v
               Streamlit Dashboard
```

### Architecture Components

**1. Streamlit Interface**

Accepts user input and displays the analysis results.

**2. LangGraph Workflow**

Controls execution order and coordinates the agents.

**3. Shared Decision State**

Stores extracted options, priorities, agent analyses, scoring information, simulations, and recommendations.

**4. Specialized Agents**

Analyze individual decision dimensions.

**5. Scoring Engine**

Calculates overall scores using weighted aggregation.

**6. Simulation Engine**

Generates illustrative future scenarios.

**7. Sensitivity Engine**

Recalculates scores using user-adjusted weights.

## ⚙️ Installation and Setup

### Prerequisites

Ensure you have:

- Python 3.10 or later
- Git
- A Groq API key

### Step 1: Clone the Repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd decisionverse
```

Replace `<YOUR_REPOSITORY_URL>` with your GitHub repository URL.

### Step 2: Create a Virtual Environment

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\activate
```

For macOS or Linux:

```bash
source .venv/bin/activate
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Configure Environment Variables

Create a `.env` file in the project root.

Add your Groq API key:

```env
GROQ_API_KEY=your_groq_api_key_here
```

Do not commit this file to GitHub.

### Step 5: Run the Application

```bash
streamlit run app.py
```

Streamlit will display the local application URL in your terminal.

Open it in your browser to use DecisionVerse.

## 🔍 How DecisionVerse Works

1. **User Input:** The user describes a decision scenario in natural language.

2. **Information Extraction:** The Extractor Agent identifies options, relevant details, and user priorities.

3. **Specialized Analysis:** Career, Finance, and Lifestyle Agents evaluate the alternatives.

4. **Risk Evaluation:** The Risk Agent identifies uncertainties and generates risk-safety assessments.

5. **Weighted Scoring:** The scoring engine combines agent scores using priority-based weights.

6. **Future Simulation:** The Simulation Agent generates illustrative scenarios for Years 1, 3, and 5.

7. **Final Recommendation:** The Decision Agent explains the preferred option and key trade-offs.

8. **Sensitivity Analysis:** Users interactively adjust scoring weights to explore alternative priorities.

## ⚠️ Limitations

DecisionVerse is a prototype decision-support system.

Current limitations include:

- Agent scores are heuristic rather than objectively verified measurements.
- Analysis quality depends on the information provided by the user.
- Missing information may result in neutral scores or uncertain assessments.
- Financial projections rely on simplified assumptions.
- Future simulations are illustrative rather than predictive.
- Risk assessments do not represent verified probabilities.
- Sensitivity analysis changes scoring weights but does not regenerate agent evaluations.
- The system does not independently verify every company-specific claim.

DecisionVerse is designed to support human judgment rather than replace it.
